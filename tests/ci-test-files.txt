# The test files outside bin/ (cloud/, plugins/, tests/) and how CI runs each: the sibling of bin/ci-test-files.txt (#1502).
# `bin/test-switchboard` (TestCiOutsideBin) derives the files from the directory tree and fails a file that is in no row and not run by a rule row,
# a row whose step is not in .github/workflows/test.yml, and an exempt row without a written reason.
# Format, one row per line:
#   chain <chain file> | <script>        every path the chain file lists is run by the workflow step that runs <script>
#   loader <runner> | <what it loads>    a test file whose module name the runner (an executable bin/test-* script) names as a string is run by it
#   run <path> | <how>                   the workflow has a step that runs this path: a `node --test` line, or the script itself with `2>&1`
#   exempt <path> | <why it is not run: at least 20 characters>
