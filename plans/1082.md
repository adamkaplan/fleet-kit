### Cause (clause 1, stated first)
In `_held_defects` (`bin/fleet-switchboard`, about line 26189 to 26201) the table rows are split on `|`, then `head = [_ascii_lower(c) for c in rows[0]]` and the test `if head != ["before", "after"] or data is None:` appends "the table needs a Before and an After column (a header row, a separator row, then the rows)" (about line 26196). So the header must equal exactly the two names in that order, and one message covers every defect (missing column, no separator, no data). The cell test `len(r) != 2` (about line 26201) also fixes the width at two. Recorded: a held pull request of another repository had `What | Before | After` and G6b answered that message. Gate G6b and `pr-explain --check` both call this function.

### Approach (what, not how)
Find the Before and After columns by trimmed, case-insensitive header name wherever they are; accept any other columns; read each data cell from those two columns; a row must still have as many cells as the header. Refuse with a message per defect: no Before column, no After column, no separator row, no data row, and a duplicated Before or After header naming the duplicate. Reads only the body.
