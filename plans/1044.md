## Plan (scenarios)

plan-format: 2
size: S (one rule in one function of the daemon file, two counters in the sweep totals, tests with three mutants, one docs paragraph; under an hour of agent time)
unchanged: S5 for a ready pull request, an expired or unreadable parked date, a missing label, and the other sweep rules

### Cause (clause 1, stated first)
`sweep_findings` in `bin/fleet-switchboard` builds the S5 finding in its last loop over `decisions`: for every decision with `tier == "cos"`, not a notice, with a `since` older than `cfg["aged_cos_hours"]`, and whose ref keys are not in `human_keys`, it adds `("S5", id)`. The test uses only the decision row (tier, kind, since, ref); the row of a pull request never carries the draft flag and the loop never looks at the item's labels or body. So a draft pull request of an ask parked until a future date is a cos-tier decision that ages, and is flagged on every sweep. The draft flag is already read (`isDraft` in the pull request list the sweep keeps), and `parked_until(body, labels)` is the one date reader the ownerless check already uses (`triage_parked_now`); S5 consults neither.

### Approach (what, not how)
S5 skips a decision whose pull request is a draft, and one whose pull request closes or belongs to an ask that is parked now (label `parked` plus a future `Parked until: YYYY-MM-DD`, read by the same reader as the ownerless check). Each skip is counted by reason and shown in the sweep's totals. Nothing else about S5 changes. The parked state comes from data the sweep already holds or from the issue read the ownerless check shares, or at most one read per distinct ask inside the sweep's budget; a read that cannot be made leaves the finding raised as before.

### Done when (copied exactly from the ask)
Done when: (1) the cause is found and stated first from the recorded case (a draft pull request of an ask parked until a future date was flagged by S5, the aged-decision rule, on every sweep): which function builds the S5 finding, what makes it count that pull request as an aged decision, and why it reads neither the draft flag nor the ask's parked state; (2) S5 skips a pull request that is a draft, and skips a pull request that closes or belongs to an ask carrying the `parked` label with a `Parked until: YYYY-MM-DD` line whose date is in the future (the same reading the ownerless check already uses), and says in the sweep's totals how many it skipped for each reason; (3) a parked date that has passed, an unreadable date, a missing label, and a pull request that is not a draft are treated exactly as before; (4) no new GitHub read per sweep beyond the ones the rule already makes (the draft flag is in the pull request list it already reads; the parked state comes from the issue read that the ownerless check shares or from one read per distinct ask, within the sweep's budget); (5) tests: a draft pull request that would otherwise age into S5 is skipped and counted; a ready pull request of a parked ask is skipped and counted; an expired date, an unreadable date and a missing label are flagged as before; a mutant that ignores the draft flag, one that ignores the parked state, and one that skips every aged decision fail; (6) the documentation names both exemptions.

### Out of scope
Other sweep rules (S1 to S3, S6 to S9); the ownerless check itself; changing `parked_until`; any label or issue write; any change of a decision's tier.

### Areas touched
`sweep_findings` and the sweep totals in `bin/fleet-switchboard` (a HELD area: the daemon file), `docs/switchboard.md` (the S5 row and the totals), tests. Not held otherwise; the floor decides.

### Risks and rollback
Risk: hiding a real aged decision, for instance a ready pull request wrongly read as parked. The strict reader treats anything unreadable as not parked, so the error direction is to flag (scenario S4). Rollback: revert the pull request; no record is written.

Stay on main.
