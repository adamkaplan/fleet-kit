# spire-land (the tool in `.spire/tool/`)

The guide is the **spire-land skill**: `.agents/skills/spire-land/SKILL.md` in the project, installed with this folder. Run `.spire/tool/bin/spire help` to print it.
The entry point is `.spire/tool/bin/spire`; the layout of `.spire/` is LAYOUT.md of the spire-land repository.
