## Cause (clause 1)

Workers push and then CI finds a failure the worker could have found: a test that reads an edited file, or a repository-wide scan of added lines. A pod cannot run the whole suite in reasonable time, and each brief re-describes by hand which tests to pick. bin/cloud-prepush replaces that hand-written rule. Rules live in cloud/README.md and the worker brief rules; the chain is bin/test-cloud-launcher (a literal && chain plus a completeness check of cloud/launcher/tests).

## Test method

New cloud/worker/tests/test_cloud_prepush.py builds throwaway git repositories in a temporary directory (a base commit, a branch with a two-file change, small fake test files) and runs bin/cloud-prepush against them. Mutant copies of the script (selector ignoring a changed file, branch-only comparison, clean on no selection) must each fail the suite. One line is added to the chain in bin/test-cloud-launcher.

## Open choices (one recommendation each)

- (a) How a test names a changed file. Recommendation: basename match (the test text contains the changed file's basename). Cost: false positives, e.g. a changed README.md selects every test mentioning any README.md; extra tests run, none are missed. Whole-path match misses tests that name a file relatively.
- (b) The repository-wide scan tests. Recommendation: a literal list inside the script, plus a test that every listed file exists. Cost: a new scan test must be added to the list by hand; a marker comment in test files would need no list but scatters the contract.
- (c) Time bound per test. Recommendation: 300 seconds each; a timeout counts as "could not run" and gives exit 1. Cost: a slow but valid test is reported as not run.
- (d) Where it runs in a pod. Recommendation: in the pod itself, with git and python3 only, needing no docker build; the base worktree sits under the temporary directory. Cost: tests that need docker count as could not run.

## Out of scope

Replacing CI as the gate; running the whole suite; installing a git hook; non-python test runners beyond executing the selected file; changes to the launcher.
